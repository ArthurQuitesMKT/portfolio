# Portfólio & Currículo Interativo — Arthur Quites

> Direção de Arte, Branding & Estratégia Visual para Engenharia

🌐 **Site no Ar:** [https://arthur-quites.vercel.app](https://arthur-quites.vercel.app)

---

## 🚀 Sobre o Projeto
Plataforma web de alta performance desenvolvida para apresentar cases de direção de arte, branding estratégico e identidade corporativa no setor de engenharia e tecnologia.

### Principais Destaques:
- **Design System Customizado:** Identidade visual com paleta dark mode e acentos em laranja institucional (#ea580c).
- **Skiper54 Slider 3D:** Carrossel interativo tridimensional com centralização fluida e modal lightbox integrado.
- **Currículo Interativo:** Visualização estruturada de trajetória, competências técnicas e certificações com cópia resiliente de contato.
- **Segurança & Boas Práticas:** Cabeçalhos de segurança HTTP (CSP, HSTS, X-Frame-Options, Permissions-Policy) auditados.
- **CI/CD Automatizado:** Pipeline integrado entre GitHub e Vercel com deploy contínuo em tempo real.

---

## 🛠️ Tecnologias Utilizadas
- **Frontend:** HTML5 Semântico, CSS3 Moderno, JavaScript ES6+
- **Bibliotecas:** Lucide Icons, GSAP (animações), Skiper54 Carousel
- **Hospedagem & Deploy:** Vercel Fluid Compute
- **Versionamento:** Git & GitHub
